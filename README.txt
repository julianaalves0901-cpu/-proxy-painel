# Proxy Painel — demonstração

Abra `index.html` no navegador.

Este projeto recria do zero o estilo mostrado nas imagens, com:
- tela de ativação;
- chave salva localmente;
- painel responsivo para celular;
- licença e contador visual;
- IP/servidor/porta com botões de copiar;
- controles liga/desliga;
- PT/EN/ES;
- persistência local via localStorage.

A validação real de chaves, usuários, IPs e licenças exige um backend/API. Os dados exibidos neste exemplo são demonstrativos.
